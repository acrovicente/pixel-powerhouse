# Pixel Powerhouse

Você é um designer UI/UX sênior, especialista em landing pages de alta conversão, branding digital e desenvolvimento de sites premium.

Crie uma landing page COMPLETA, moderna, sofisticada e extremamente profissional para uma empresa que vende criação de sites, landing pages e páginas de alta conversão para empresas e profissionais.

OBJETIVO PRINCIPAL DA PÁGINA:

Transformar visitantes em potenciais clientes.

A página deve apresentar meus serviços, mostrar exemplos de sites que posso criar e fazer o visitante entrar em contato comigo pelo WhatsApp para solicitar orçamento.

O visitante precisa entender rapidamente:

1. O que eu faço.

2. Para quem eu faço.

3. Que tipo de site posso criar.

4. Como o site pode ajudar o negócio a conseguir mais clientes.

5. Que os projetos são personalizados.

6. Como entrar em contato para negociar o projeto.
